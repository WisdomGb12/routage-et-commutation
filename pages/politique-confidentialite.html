Politique de Confidentialité

1. Absence de collecte de données personnelles

Ce site ne collecte, ne traite et ne stocke aucune donnée personnelle vous concernant. Aucun formulaire d'inscription, aucun système de connexion utilisateur et aucun serveur backend ou base de données ne sont associés à ce site.

2. Stockage local de la progression (localStorage)

Afin de mémoriser votre navigation (sections marquées comme lues, réponses et scores aux quiz, choix du thème clair/sombre), le site utilise l'API localStorage intégrée à votre navigateur.

  • Ces données sont stockées exclusivement sur votre appareil.
  • Elles ne sont jamais transmises à un serveur distant ni partagées avec des tiers.
  • Vous pouvez effacer ces données à tout moment en vidant le cache ou les données de stockage de votre navigateur web.

3. Hébergement par GitHub Pages

Ce site est hébergé de manière statique via GitHub Pages (service opéré par GitHub, Inc. / Microsoft).

Dans le cadre de cet hébergement technique, GitHub peut collecter des données de connexion brutes (telles que les adresses IP des visiteurs et les chaînes User-Agent) à des fins de sécurité et de maintenance des infrastructures réseau. Cette collecte est régie par la déclaration de confidentialité de GitHub :

Déclaration de confidentialité de GitHub

4. Cookies, Publicités et Outils d'analyse

À ce jour, le site :

  • N'utilise aucun cookie traceur ou publicitaire.
  • N'affiche aucune publicité.
  • N'intègre aucun outil d'analyse d'audience tiers (tel que Google Analytics, Matomo, etc.).

Si ces choix techniques venaient à évoluer à l'avenir, cette présente politique de confidentialité sera mise à jour en conséquence.
